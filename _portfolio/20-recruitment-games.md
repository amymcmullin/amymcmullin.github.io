**Play them:** [CSIT games →](/games/csit-games.html) · [Cybersecurity games →](/games/cybersecurity-games.html)

## Why

Our program pages tell people what they will learn, but they don't let anyone try it. I wanted a page where a prospective student could spend a few minutes doing a small piece of the actual work and then see the Apply button.

Two decisions shaped the build:

* **Variety over one big game.** Each page has four short games that feel different from each other: a puzzle, a hands-on build, a timed challenge and a decision game. If someone doesn't like one, the next one may suit them better.
* **Three languages.** English, Spanish and Haitian Creole, the three languages our applicants speak, switched with one button and remembered across both pages.

## The games

**Computer Systems & IT**

| Game | What it teaches |
|---|---|
| Cable Connect | Rotate cable tiles until every computer reaches the server: network topology as a puzzle |
| Build-a-PC | Put the CPU, RAM, SSD, graphics card and power supply in the right slots, then boot it |
| Binary Blitz | Flip bits to make target numbers before a 60-second clock runs out |
| Help Desk Hero | Choose the best first troubleshooting step for five real-world tickets |

**Applied Cybersecurity**

| Game | What it teaches |
|---|---|
| Phish or Legit? | Sort six emails from made-up companies and see the warning signs in each |
| Password Cracker | Watch the estimated time to brute-force a practice password change as you type |
| Code Breaker | Decode Caesar-cipher messages with a shift wheel |
| Firewall Defender | Allow or block incoming packets by port and source before they reach the server |

The Cybersecurity page points people back to CSIT first, because that is the sequence our local employers asked for.

Each page is a single self-contained HTML file with no external libraries, tracking or data collection, so it can be uploaded to the college site or embedded as-is.

*The games were built with AI assistance (Claude). I set the requirements: two programs, a variety of game types for different players, three languages, a single-file format for the college website, and an apply call to action. The Haitian Creole text is pending review by a native speaker before the pages go on the college site.*
